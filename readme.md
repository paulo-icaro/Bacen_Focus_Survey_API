## Guidethrough

<p>

      The [**Focus Survey**]('https://www.bcb.gov.br/publicacoes/focus')
is an important source of market expectations about Brazilian
macroeconomic variables. The Central Bank of Brazil publishes a weekly
report summarizing the expectations of financial institutions and
analysts regarding the country’s main economic indicators.\
      This library allows researchers to access daily data on
expectation for macroeconomic variables such as price indexes and
nominal interest rates across different forecast horizons.\
      Further details on how to extract the data are available in the
following:

      Readme - [English Tutorial](tutorial_en.md)\
      Leiame - [Tutorial em Português](tutorial_pt_br.md)

</p>
